# Clotho v1 JSON Schema

정식 machine-readable schema는 package의 `@kokoa/clotho/schema.json`입니다. 이 페이지는 사람이 문서를 작성할 때 필요한 전체 구조를 설명합니다.

## 최상위 문서

| 필드 | 형식 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `clothoVersion` | literal `1` | 필수 | 포맷 식별자 |
| `$schema` | string? | 없음 | editor autocomplete용 URL |
| `id` | ID | 필수 | 문서 ID |
| `title` | string | `""` | 제목 |
| `description` | string | `""` | 설명 |
| `category` | string | `general` | 자유 category |
| `tags` | string[] | `[]` | 검색·분류 tag |
| `duration` | 0 이상 정수 | `5000` | 전체 시간(ms) |
| `canvas` | object | 800×500 | stage 크기와 배경 |
| `assets` | object map | `{}` | image registry |
| `elements` | element[] | `[]` | document order의 요소 |
| `chapters` | chapter[] | `[]` | 단계와 caption |
| `effects` | effect[] | `[]` | 일시적인 강조 |
| `settings` | object | 아래 참조 | player 표시 의도 |
| `updatedAt` | string? | 없음 | host가 관리하는 시각 |

`canvas`: `width`와 `height`는 양의 정수이며 `background`는 CSS color 또는 `transparent`입니다.

`settings`: `loop`, `autoplay`, `showCaption`, `showChapterList`는 boolean이고, `chapterListPosition`은 `left | right | top | bottom`입니다.

`chapter`: `id`, 0 이상 정수 `time`, `label`, `subtitle`로 구성합니다.

## 모든 요소의 공통 필드

| 필드 | 형식 | 기본값 |
| --- | --- | --- |
| `type` | 요소 discriminator | 필수 |
| `id` | ID | 필수 |
| `name` | string? | 없음 |
| `parentId` | ID? | 없음 |
| `rotation` | number | `0` |
| `appearances` | Appearance[] | `[]` |
| `tracks` | PropertyTrack[] | `[]` |

## 요소별 필드

### rect

필수: `x`, `y`, 양수 `width`, 양수 `height`. 선택 및 기본값: `fill #a5b4fc`, `stroke #6366f1`, `strokeWidth 1.5`, `cornerRadius 8`, `label?`, `labelColor #0b0b0f`, `labelSize 14`, `subtitle?`, `subtitleSize?`.

### circle

필수: `cx`, `cy`, 양수 `r`. 선택 및 기본값: `fill`, `stroke`, `strokeWidth`, `label?`, `labelColor`, `labelSize`는 rect와 같습니다.

### line과 arrow

좌표 endpoint는 `x1`, `y1`, `x2`, `y2`, 연결 endpoint는 `fromId`, `toId`, `fromAnchor`, `toAnchor`입니다. `strokeDasharray?`, `headStart?`, `headEnd?`, `stroke #6366f1`, 양수 `strokeWidth 2`를 지원합니다.

arrow 추가 필드: `label?`, `labelColor #0b0b0f`, `labelOffsetX 0`, `labelOffsetY 4`, `curvature 0`.

### text

필수: `x`, `y`, `content`. 기본값: `fontSize 16`, `fontWeight 400`, `color #18181b`, `textAnchor start`. `textAnchor`는 `start | middle | end`입니다.

### image

필수: `x`, `y`, 양수 `width`, 양수 `height`, `assetId`. 선택: `alt?`, `preserveAspectRatio "xMidYMid meet"`, 0~1 `opacity 1`.

### path

필수: SVG `d`. 기본값: `x 0`, `y 0`, `fill none`, `stroke #6366f1`, `strokeWidth 2`, `opacity 1`. `strokeDasharray?`를 지원합니다.

### polygon

필수: SVG `points` 문자열. 기본값: `fill #a5b4fc`, `stroke #6366f1`, `strokeWidth 1.5`, `opacity 1`.

### group

`x 0`, `y 0`을 사용합니다. 자식은 group이 ID 배열을 갖는 대신 각 요소의 `parentId`로 group을 가리킵니다.

### code

필수: `x`, `y`, 양수 `width`, 양수 `height`, `content`. 기본값: `language javascript`, `fontSize 12`, `showLineNumbers false`, `fill #1e293b`, `textColor #e2e8f0`, `padding 12`, `cornerRadius 8`. `title?`을 지원합니다.

## Appearance

```json
{
  "start": 0,
  "end": 2000,
  "entryMode": "fade",
  "entryDuration": 300,
  "exitMode": "slide-left",
  "exitDuration": 300
}
```

`start`, `end`는 0 이상 정수입니다. mode는 `instant`, `fade`, 네 방향 slide, `zoom`, `pop`입니다.

## PropertyTrack

```json
{
  "property": "fill",
  "interpolate": "color",
  "keyframes": [
    { "time": 0, "value": "#6366f1", "ease": "linear" },
    { "time": 1200, "value": "#22c55e", "ease": "easeInOut" }
  ]
}
```

keyframe의 `time`은 0 이상 정수, `value`는 string·number·boolean입니다. keyframe은 시간순으로 작성하세요.

## Asset

```json
{
  "logo": { "kind": "external", "url": "https://example.com/logo.png" },
  "avatar": { "kind": "ref", "key": "media/avatar" },
  "icon": { "kind": "inline", "mime": "image/png", "data": "iVBORw0..." }
}
```

inline `data`에는 `data:image/...;base64,` prefix를 넣지 않습니다. image 요소의 `assetId`는 반드시 존재하는 key를 가리켜야 합니다.

## Effect

- highlight: 공통 필드 + `color #facc15`, `duration 500`
- pulse: 공통 필드 + 양수 `scale 1.12`, `duration 500`
- flow: 공통 필드 + `color #facc15`, `particles 3`(1~10), 양수 `radius 4`, `duration 800`

공통 필드는 `type`, `id`, `elementId`, `time`입니다.

## 의미 검증

Zod parse 이후에도 `validateDocument`로 다음 항목을 확인하세요.

- 중복 ID와 존재하지 않는 element·asset·parent 참조
- group이 아닌 부모와 parent cycle
- connector endpoint 누락
- chapter, keyframe, appearance와 effect가 duration 밖에 있는지 여부
- appearance의 `start <= end`와 keyframe 시간순
- 지원하지 않는 track property 및 asset MIME

```bash
bunx clotho validate animation.json --strict
```

legacy의 `version: 3 | 4`는 v1이 아닙니다. `clotho migrate animation.json --write`로 변환한 뒤 검증하세요.
