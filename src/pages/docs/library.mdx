# 코드 라이브러리

`@kokoa/clotho`는 JSON 문서를 검증하고 특정 시각의 장면을 계산하는 핵심 라이브러리입니다. 화면을 직접 편집할 때는 [Clotho 편집기](/docs/editor)를, 애플리케이션 코드에서 재생하거나 SVG와 GIF를 만들 때는 이 라이브러리를 씁니다.

## 무엇을 설치해야 하나요?

```bash
npm install @kokoa/clotho
```

React 플레이어를 쓸 때는 React와 React DOM도 함께 설치합니다.

```bash
npm install @kokoa/clotho react react-dom
```

## 진입점

| 진입점 | 역할 |
| --- | --- |
| `@kokoa/clotho` | 스키마, 런타임, 작성 도우미, 레이아웃, 데이터 연결, 스토리, 린터 |
| `@kokoa/clotho/react` | React 플레이어와 무대, 그리고 훅 |
| `@kokoa/clotho/vue` | Vue 플레이어와 무대, 그리고 컴포저블 |
| `@kokoa/clotho/dom` | 바닐라 DOM 플레이어와 장면 갱신 |
| `@kokoa/clotho/svg` | 결정적인 SVG 문자열 생성 |
| `@kokoa/clotho/node` | 파일 불러오기와 GIF 만들기 |
| `@kokoa/clotho/testing` | 애니메이션 단언과 시각 회귀 검사 도구 |
| `@kokoa/clotho/plugins` | 플러그인 API 전용 진입점 |
| `@kokoa/clotho/mdx` | 마크다운·MDX 삽입 빌더와 활성화 |
| `@kokoa/clotho/element` | `<clotho-player>` 커스텀 엘리먼트 |

## 가장 작은 사용 예

```tsx
import { animationDocumentSchema } from "@kokoa/clotho";
import { AnimationPlayer } from "@kokoa/clotho/react";
import "@kokoa/clotho/styles.css";

const document = animationDocumentSchema.parse(input);

export function Example() {
  return <AnimationPlayer doc={document} theme="auto" />;
}
```

## 기능을 선택하는 기준

- 되풀이되는 장면을 코드로 만들 때는 `defineTemplate`과 매개변수를 씁니다.
- API 응답이나 고정된 JSON 값을 이어 붙일 때는 데이터 연결을 씁니다.
- 요소 사이의 간격과 정렬을 유지할 때는 제약 레이아웃을 씁니다.
- 읽는 사람의 응답을 기다릴 때는 체크포인트를 씁니다.
- 여러 문서로 갈라지는 흐름은 `StoryManifest`로 구성합니다.
- 바깥 폭에 따라 무대를 바꿀 때는 반응형 변형을 씁니다.
- 배포 전에 `validateDocument`와 `lintDocument`, 그리고 시각 회귀 검사를 돌립니다.

각 기능의 관계와 실행 순서는 [확장형 작성 환경](/docs/authoring-platform), 전체 공개 함수는 [API와 hooks](/docs/api)에서 확인할 수 있습니다.

## 편집기와 역할이 어떻게 갈리나

이 라이브러리는 문서의 뜻을 해석하고, 계산하고, 그리는 일을 맡습니다. 편집기는 같은 스키마 위에서 문서를 만드는 화면입니다. 편집기가 저장한 JSON을 다시 `@kokoa/clotho`로 검증하고 재생하므로, 둘 사이에 따로 변환 계층을 둘 필요가 없습니다.
