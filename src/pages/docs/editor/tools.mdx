# 도구와 Canvas

도구 버튼을 누르는 순간 요소가 생성되지는 않습니다. 먼저 도구를 활성화한 뒤 Canvas에서 클릭하거나 drag하여 위치와 크기를 결정합니다.

## 선택과 크기 조절

`V`로 선택 도구를 활성화합니다. 요소를 선택하면 이동과 크기 조절 handle이 표시됩니다. `Shift`, `Ctrl` 또는 `Command`를 누른 채 클릭하면 여러 요소를 추가하거나 제외할 수 있습니다. 입력창과 Text 편집 중에는 도구 단축키를 실행하지 않습니다.

## 도형 만들기

| 도구 | 단축키 | 사용법 |
| --- | --- | --- |
| Rectangle | `R` | 클릭하면 기본 크기, drag하면 지정한 영역으로 생성 |
| Circle | `O` | 클릭하거나 drag해 지름을 지정하고 handle로 크기 변경 |
| Line | `L` | 시작 요소와 끝 요소의 anchor를 차례로 선택 |
| Arrow | `A` | Line과 같은 방식으로 연결하고 화살표 모양을 선택 |
| Text | `T` | 배치한 뒤 두 번 클릭하여 Canvas 안에서 직접 편집 |
| Image | `I` | Host upload hook 또는 Base64 변환으로 asset 등록 |
| Path | `B` | Canvas를 연속 클릭해 경로 점 추가 |
| Polygon | `Y` | toolbar 또는 오른쪽 panel에서 변 개수 지정 |

## Anchor와 connector

요소의 가운데뿐 아니라 위·아래·좌·우와 네 모서리를 연결점으로 사용할 수 있습니다. 저장된 `fromAnchor`와 `toAnchor`는 요소가 움직이거나 group transform이 적용되어도 같은 경계를 추적합니다.

## Group

여러 요소를 선택해 Group으로 만들면 요소 목록에서도 자식이 계층적으로 표시됩니다. Group의 이동과 회전은 자식 전체에 적용되며, Timeline에는 실제로 animation 속성을 가진 요소와 track만 표시합니다.
