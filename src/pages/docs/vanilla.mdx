# Vanilla JS에서 사용하기

React나 Vue 없이 사용하는 경우 `@kokoa/clotho/dom`의 `mountPlayer`로 기존 HTML 요소에 Player를 연결합니다.

## HTML과 JavaScript

```html
<div id="animation"></div>
```

```ts
import { parseDocumentOrThrow } from "@kokoa/clotho";
import { mountPlayer, koreanStrings } from "@kokoa/clotho/dom";
import "@kokoa/clotho/styles.css";

const source = await fetch("/animations/example.json").then((response) =>
  response.json(),
);
const animationDocument = parseDocumentOrThrow(source);
const container = document.querySelector<HTMLElement>("#animation");

if (!container) throw new Error("애니메이션 영역을 찾지 못했습니다.");

const handle = mountPlayer(container, animationDocument, {
  theme: "auto",
  strings: koreanStrings,
});

// 화면을 제거할 때 observer, event와 player도 함께 정리합니다.
window.addEventListener("pagehide", () => handle.destroy(), { once: true });
```

## 직접 제어

`mountPlayer`가 반환하는 `handle.player`에서 `play()`, `pause()`, `seek(time)`, `restart()`와 `setSpeed(speed)`를 호출할 수 있습니다. 현재 상태는 `getState()`로 읽고 `subscribe()`로 변경을 구독합니다.

Player UI가 필요 없으면 `mountStage`를 사용하여 지정한 시간의 SVG 장면만 표시할 수 있습니다.
