# 기능과 표현

Clotho의 기능은 JSON 문서, 결정적인 runtime, scene builder와 환경별 adapter로 나뉩니다. 같은 문서와 같은 시간이 주어지면 모든 adapter가 같은 장면을 표현합니다.

작성 단계에서 함께 사용하는 plugin, constraint, template, data binding, checkpoint, 반응형 stage, linter와 visual regression은 [확장형 작성 환경](/docs/authoring-platform)에서 하나의 흐름으로 설명합니다.

## 표현 요소

각 요소의 페이지에서 모든 고유 옵션, 실행되는 애니메이션과 전체 JSON을 함께 확인할 수 있습니다.

### 도형과 내용

- [`rect` — Rectangle](/docs/elements/rect): 카드, 배열 칸과 영역
- [`circle` — Circle](/docs/elements/circle): 그래프 노드와 상태점
- [`text` — Text](/docs/elements/text): 설명, 수식과 상태 문구
- [`image` — Image](/docs/elements/image): asset registry의 이미지
- [`code` — Code](/docs/elements/code): 구문 강조를 지원하는 code block

### 연결과 자유 도형

- [`line` — Line](/docs/elements/line): 좌표 또는 anchor를 잇는 연결선
- [`arrow` — Arrow](/docs/elements/arrow): 방향과 label을 가진 연결선
- [`path` — Path](/docs/elements/path): 자유로운 SVG path
- [`polygon` — Polygon](/docs/elements/polygon): points로 정의하는 다각형

### 구조

- [`group` — Group](/docs/elements/group): 자식 요소에 적용되는 공통 transform과 visibility

모든 요소는 `id`, `name?`, `parentId?`, `rotation`, `appearances`, `tracks`를 공통으로 가집니다. ID는 소문자 영문이나 숫자로 시작하며 이후 소문자 영문, 숫자, `-`, `_`만 사용합니다.

Text는 기본 문구와 언어별 번역을 함께 저장할 수 있습니다. 문서와 요소별 언어 목록, locale 선택과 fallback 규칙은 [Text 국제화](/docs/i18n)에서 확인하세요.

## 등장과 퇴장

`appearances`는 요소가 보이는 시간 구간입니다. 여러 구간을 넣으면 하나의 요소가 반복해서 나타났다 사라질 수 있습니다.

| mode                        | 표현                    |
| --------------------------- | ----------------------- |
| `instant`                   | 즉시 표시 또는 숨김     |
| `fade`                      | opacity 변화            |
| `slide-left`, `slide-right` | 가로 이동               |
| `slide-up`, `slide-down`    | 세로 이동               |
| `zoom`                      | scale 변화              |
| `pop`                       | 짧은 확대를 포함한 등장 |

각 구간은 `start`, `end`, `entryMode`, `entryDuration`, `exitMode`, `exitDuration`을 사용합니다.

## Property track

`tracks`는 시간에 따라 요소 속성을 바꿉니다. 하나의 track은 `property`, `interpolate`, `keyframes`로 구성합니다.

- ease: `linear`, `easeIn`, `easeOut`, `easeInOut`
- interpolation: `auto`, `number`, `color`, `discrete`
- value: string, number 또는 boolean

`auto`는 알려진 숫자·색상·텍스트 속성을 자동 분류합니다. 의도를 명확히 하거나 사용자 정의 속성을 다룰 때는 interpolation을 직접 지정하세요.

## 강조 Effect

| effect      | 필드                                       | 동작                        |
| ----------- | ------------------------------------------ | --------------------------- |
| `highlight` | `color`, `duration`                        | 지정한 요소에 강조색 적용   |
| `pulse`     | `scale`, `duration`                        | 지정한 요소를 확대했다 복원 |
| `flow`      | `color`, `particles`, `radius`, `duration` | connector를 따라 입자 이동  |

공통 필드는 `id`, `elementId`, `time`입니다. Effect는 요소의 track을 바꾸지 않는 일시적인 장식입니다.

## Connector

line과 arrow는 두 방식 중 하나로 끝점을 정합니다.

- 절대 좌표: `x1`, `y1`, `x2`, `y2`
- 요소 추적: `fromId`, `toId`, `fromAnchor`, `toAnchor`

anchor는 `auto`, `top`, `right`, `bottom`, `left`, `center`, 네 대각선(`top-left` 등)을 지원합니다. head는 `none`, `arrow`, `triangle`, `triangle-open`, `circle`, `circle-open`, `diamond`, `diamond-open`, `bar`를 양 끝에 독립적으로 지정합니다.

## Chapter와 Player UI

chapter는 `id`, `time`, `label`, `subtitle`로 구성합니다. `settings`에서 현재 caption과 chapter 목록을 켜고 목록 위치를 `left`, `right`, `top`, `bottom`으로 선택합니다. chapter가 없으면 목록과 caption 영역은 표시하지 않습니다.

## 이미지 Asset

문서의 `assets`는 ID를 key로 쓰는 map입니다.

- `inline`: `mime`과 prefix 없는 raw base64 `data`
- `external`: 공개 또는 host가 허용한 `url`
- `ref`: host의 `AssetResolver`가 해석하는 `key`

image 요소는 URL을 직접 저장하지 않고 `assetId`를 참조합니다. 여러 요소가 같은 asset을 재사용할 수 있습니다.

## Theme와 접근성

`AnimationPlayer`의 `theme`은 `auto`, `light`, `dark`를 지원합니다. `auto`는 host 문서의 `color-scheme`과 OS 설정을 따릅니다. player는 `prefers-reduced-motion`을 감지하면 정지된 장면을 제공하고, 화면 밖에서는 clock을 멈춥니다. image에는 의미를 설명하는 `alt`를 지정하세요.

## 출력 환경

- React: `AnimationPlayer`, `AnimationStage`, hooks
- Vue: `AnimationPlayer`, `AnimationStage`, `usePlayer`
- DOM: `mountPlayer`, `mountStage`, scene patching
- SVG: 문자열 또는 standalone SVG 생성
- Node.js: 파일 loading, GIF 생성
- CLI: validate, migrate와 파일 기반 작업

공개 함수와 option은 [API와 hooks](/docs/api), 정확한 JSON 필드는 [JSON Schema](/docs/schema)에서 확인할 수 있습니다.
